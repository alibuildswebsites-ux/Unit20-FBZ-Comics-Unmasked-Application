# Dataset provenance

The integrated dataset is the British Library **Comics Unmasked** Researcher Format package dated April 2022, matching the dataset description in the supplied Unit 20 assignment brief.

- Archive: `data/raw/ComicsResearcherFormat_202204_csv.zip`
- Extracted files: `records.csv`, `names.csv`, `titles.csv`, `topics.csv`, `classification.csv`
- Supporting readme: `data/raw/extracted/Readme - Comics Unmasked.txt`
- Supporting dataset description PDF: `data/raw/extracted/british_library_catalogue_dataset_tc.pdf`
- Archive was recovered from an Internet Archive snapshot of the original British Library download URL because the historical direct URL now returns 404.
- SHA-256 of integrated archive is recorded in `reports/dataset_sha256.txt`.
